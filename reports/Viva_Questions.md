# Viva Questions and Short Answers

1. **What is machine learning?** A method that learns patterns from data to make predictions or decisions.
2. **What is classification?** Predicting a discrete class label, such as a dataset's 0/1 target.
3. **Why use separate models?** Each dataset has different features and target definitions.
4. **What is Random Forest?** An ensemble of decision trees whose outputs are combined.
5. **Why split data into train and test?** To estimate performance on data not used for fitting.
6. **What is accuracy?** Correct predictions divided by total predictions.
7. **What is precision?** Among predicted positives, the proportion that are true positives.
8. **What is recall?** Among actual positives, the proportion detected by the model.
9. **What is F1-score?** The harmonic mean of precision and recall.
10. **What is data leakage?** Information from outside the training process improperly influences evaluation or training.
11. **Why use a pipeline?** It keeps preprocessing and model fitting together consistently.
12. **Why median imputation?** It fills missing numeric values using the training data's median.
13. **What is Streamlit?** A Python framework for interactive data applications.
14. **What are the limitations?** Dataset bias, small samples, distribution shifts and lack of clinical validation.
15. **Can the project diagnose a patient?** No. It is an educational prototype, not a medical device.
16. **Why is Parkinson's evaluation tricky?** Several voice recordings may come from the same participant; row-wise splitting can leak participant information.
17. **What is a confusion matrix?** A table showing actual versus predicted classes.
18. **What is model persistence?** Saving a trained model so it can be loaded later.
19. **What is a target column?** The label the model is trained to predict.
20. **What are future improvements?** Grouped validation, external datasets, explainability, testing and secure deployment.
